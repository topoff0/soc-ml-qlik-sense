# Контрольные расчёты

## Практика 3. SHAP

- Продуктивный срез — **20 584** уникальные карточки и **73** признака на карточку. Ожидаемое число вкладов — `20 584 × 73 = 1 502 632`.
- Для каждой карточки рассчитано `z = base + Σ SHAP`. Вклады и база выражены в логарифме шансов. Восстановленная вероятность равна `1 / (1 + exp(−z))`.
- Максимум `|восстановленная вероятность − исходная оценка|` равен **2,40 × 10⁻⁷**. Карточек выше допуска **5 × 10⁻⁷** — **0**.
