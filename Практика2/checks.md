# Контрольные расчёты

## Практика 2. Инференс

- Строк журнала - **19 393**. Для метрик качества включены строки с `y ∈ {0, 1}` - **15 839**. Покрытие бинарными вердиктами - `15 839 / 19 393 = 81,7%`. Остальные 3 554 строки исключены из оценки качества.
- `y = 1` означает подтверждённый инцидент. `y_pred = 1` означает, что модель отнесла карточку к инцидентам. Решение по `true_incident_proba ≥ 0,18` совпало с сохранённым `y_pred` на всех 19 393 строках.

| Вердикт SOC | Модель отметила инцидент | Модель сочла карточку легитимной | Всего |
| --- | ---: | ---: | ---: |
| Инцидент | 1 331 (TP) | 335 (FN) | 1 666 |
| Легитимно | 2 563 (FP) | 11 610 (TN) | 14 173 |
| Всего | 3 894 | 11 945 | 15 839 |

- Доля пропусков - `FN / (TP + FN) = 335 / 1 666 = 20,1%`.
- Согласие с вердиктом - `(TP + TN) / 15 839 = 81,7%`.
- Доля подтверждений среди помеченных моделью инцидентов с вердиктом - `TP / (TP + FP) = 1 331 / 3 894 = 34,2%`.
