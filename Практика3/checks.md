# Контрольные расчёты

## Практика 3. SHAP

- В учебном наборе № 7 по две карточки каждого исхода TP, FP, FN и TN. Для восьми карточек загружены все 73 вклада. Всего `8 × 73 = 584`.
- Для каждой карточки рассчитано `z = base + Σ SHAP`. Вклады и база выражены в логарифме шансов. Восстановленная вероятность равна `1 / (1 + exp(−z))`.
- Максимальная абсолютная разница между восстановленной вероятностью и оценкой модели составила **3,50 × 10⁻⁸**. Все карточки прошли проверку с допуском **5 × 10⁻⁷**.
